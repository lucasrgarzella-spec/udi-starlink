# UDI Starlink

Site institucional da **UDI Starlink**, focado na apresentação dos serviços de internet via satélite Starlink em Uberlândia e região.

## 🚀 Serviços
- Internet via satélite Starlink
- Alta velocidade em áreas urbanas e rurais
- Suporte e instalação especializada

## 📍 Localização
Uberlândia – MG

Este repositório contém apenas o **frontend institucional** do site.
